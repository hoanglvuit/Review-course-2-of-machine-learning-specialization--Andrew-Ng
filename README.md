# Machine Learning Specialization - Review Course 2

## Giới thiệu

Đây là một phần của bộ tài liệu từ khóa học "Machine Learning Specialization" của Andrew Ng, cụ thể là Review Course 2. Dự án này chứa các file PDF được tổng hợp để giúp bạn ôn lại và nắm vững các khái niệm quan trọng trong phần học này.

## Giới thiệu về khóa học

Khóa học "Machine Learning Specialization" của Andrew Ng, được giảng dạy trên Coursera, bao gồm nhiều phần học từ cơ bản đến nâng cao, giúp bạn hiểu rõ về các thuật toán học máy, bao gồm:

- Học có giám sát
- Học không giám sát
- Các phương pháp học máy nâng cao
- Và các ứng dụng thực tế trong các lĩnh vực như nhận dạng hình ảnh, dự đoán, v.v.
